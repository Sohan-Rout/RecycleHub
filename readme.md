# ♻️ RecycleHub Backend

This is the backend API server for the **RecycleHub** and **SellerHub** ecosystem. Built using **Node.js** and **Express.js**, it powers core functionalities like user authentication, carbon calculation, recyclability checks, item pickups, and product listings.

---

## 🛠️ Tech Stack

- **Node.js** with **Express.js**
- **MongoDb**
- **Cloudinary**
- **CORS & Middleware**
- **Gemini Api**
